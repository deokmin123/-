🤖 Claude AI로 역사 답변 받기

이 도구는 API 없이 사이트 링크만 제공해요. AI 답변은 Claude.ai를 활용하면 무료로 받을 수 있어요.
아래 프롬프트(지시문)를 Claude.ai 프로젝트에 한 번만 설정해두면, 이후 질문할 때마다 자동으로 상세한 역사 답변 + 자료 사이트 링크를 함께 제공받을 수 있어요.

1
Claude.ai 접속아래 링크를 눌러 Claude.ai에 접속하세요. 무료 계정으로도 사용 가능해요.
2
프로젝트 만들기왼쪽 사이드바 → Projects → New Project → 이름: "역사 자료 탐구 AI"
3
지시문 붙여넣기아래 "지시문 복사" 버튼 클릭 → 프로젝트 설정의 Custom Instructions에 붙여넣기
4
바로 사용!프로젝트 안에서 새 채팅 열고 역사 질문을 입력하면 상세한 답변 + 자료 링크를 받을 수 있어요.

💡 Claude.ai 프로젝트 설정 방법 (상세)
  1. claude.ai 접속 후 로그인 (구글 계정으로 간편 가입 가능)
  2. 왼쪽 사이드바에서 Projects 클릭
  3. New Project 클릭 → 프로젝트 이름 입력 (예: 역사 자료 탐구 AI)
  4. 프로젝트 페이지에서 ⚙️ Project Settings 또는 Edit 클릭
  5. Custom Instructions 칸에 복사한 지시문 붙여넣기
  6. 저장 후 프로젝트 안에서 New Chat 열기
  7. 역사 인물, 사건, 시대를 자유롭게 질문하세요!
📖 이 도구 사용 방법
💡 핵심 사용 흐름
① 이 페이지(사이트 검색 탭)에서 키워드 입력 → 관련 자료 사이트 링크 클릭 → 원문 확인
② Claude.ai 프로젝트에서 같은 키워드 질문 → AI가 내용 정리 + 자료 사이트 링크 제공
두 가지를 함께 활용하면 가장 효율적으로 역사 자료를 탐구할 수 있어요.
🔍 키워드 입력 방법
인물명, 사건명, 시대명을 입력하면 돼요.

예시:
· 이순신 / 세종대왕 / 광개토대왕
· 임진왜란 / 3.1운동 / 한국전쟁
· 조선시대 / 고려 / 신라
· Yi Sun-sin (영어도 가능)

입력 후 Enter 또는 검색하기 버튼을 누르면 해당 키워드로 각 사이트 검색 결과에 연결되는 버튼들이 나타나요.
🟢 검색 연결 vs 🔵 홈페이지 연결
🟢 초록색 (검색 연결):
버튼을 클릭하면 입력한 키워드로 검색된 결과 페이지로 바로 이동해요.

🔵 파란색 (홈페이지 연결):
해당 사이트 구조상 URL로 검색이 불가능해요. 클릭하면 사이트 메인 페이지로 이동하니, 거기서 직접 검색창에 키워드를 입력하세요.

왜 차이가 나나요?
일부 사이트는 보안 또는 구조적 이유로 URL만으로 검색이 안 돼요. 이런 사이트는 홈페이지 링크만 제공하고 직접 검색을 안내해요.

🔑 원문 읽기가 어려울 때
한문·일본어·프랑스어 등 원문을 읽기 어려울 때는 Claude.ai에 원문 이미지나 텍스트를 붙여넣고 번역·해석을 요청해보세요. "이 한문 원문을 현대 한국어로 번역하고 내용을 설명해줘"와 같이 질문하면 도움을 받을 수 있어요.
📌 회원제 사이트 안내
일부 사이트(영국 신문문서보관소 등)는 유료 회원제로 운영돼요. 그런 경우 대학 도서관을 통해 무료로 접근할 수 있는 경우가 많으니 소속 기관의 도서관 데이터베이스를 확인해보세요.
